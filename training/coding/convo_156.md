### Prerequisites for Installing Gravity Forms
Before diving in, ensure you have:
- A WordPress website with admin access (you should be able to log in as an administrator).
- A Gravity Forms license. It's a premium plugin, so you'll need to purchase one from their website (gravityforms.com). If you don't have a license yet, grab that first to avoid installation issues.

If you're not sure about your admin access or license status, log into your WordPress dashboard (usually at yoursite.com/wp-admin) and confirm. This prevents common hiccups like permission errors.

### Step-by-Step Installation Guide
Follow these steps to install Gravity Forms on your WordPress site. The process is straightforward and doesn't require coding.

1. **Purchase and Download the Plugin**  
   Go to gravityforms.com, select a plan that fits your needs (e.g., basic for simple forms), and complete the purchase. You'll receive an email with your license key and a download link for the plugin file (.zip format). Save this file to your computer.

2. **Log Into Your WordPress Dashboard**  
   Navigate to yoursite.com/wp-admin and enter your username/password. This takes you to the admin panel.

3. **Navigate to the Plugin Installer**  
   In the left sidebar, go to Plugins > Add New. This opens the plugin installation page.

4. **Upload and Install the Plugin**  
   Click the "Upload Plugin" button at the top. Choose the Gravity Forms .zip file you downloaded, then click "Install Now." WordPress will upload and install it automatically—wait for the "Plugin installed successfully" message.

5. **Activate the Plugin**  
   After installation, click "Activate Plugin." You'll be prompted to enter your license key from the purchase email. Paste it in and activate. This unlocks all features and ensures updates work.

6. **Verify Installation**  
   Check the left sidebar for a new "Forms" menu item. If it's there, you're good. If not, double-check your license key or refresh the page.

Common issue: If you get an error like "Upload failed" during step 4, it might be a file size limit on your hosting—contact your host to increase it, or try installing via FTP if you're comfortable.

### Basic Setup: Creating Your First Contact Form
Once installed, let's get you a working contact form quickly.

1. **Access the Forms Menu**  
   From your dashboard, go to Forms > New Form.

2. **Choose a Template or Start Blank**  
   Gravity Forms offers pre-built templates. For a contact form, select something like "Simple Contact Form" or build from scratch. Click "Create Form."

3. **Add Fields**  
   Drag and drop fields from the left panel:  
   - Single Line Text for Name  
   - Email for Email Address  
   - Textarea for Message

4. **Configure Settings**  
   Go to the Settings tab: Set up email notifications so submissions go to your inbox. Under Form Settings, enable anti-spam features like honeypot or reCAPTCHA if you have it.

5. **Save and Embed the Form**  
   Save the form. To add it to a page, go to Pages > Add New (or edit an existing page like "Contact"). Use the Gravity Forms block (if using Gutenberg editor) or shortcode (found under Form Settings > Embed). Preview and publish.
