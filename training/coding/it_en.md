BOT: Spear phishing is a highly targeted phishing attack customized for a specific individual, organization, or business to increase the chances of success.

USER: What is Whaling?
BOT: Whaling is a specific form of spear phishing targeted at high-profile business targets such as C-level executives (CEOs, CFOs).

USER: What is Vishing?
BOT: Vishing, or voice phishing, is the use of telephony (often VoIP) to conduct phishing attacks, deceiving victims into revealing personal information over the phone.

USER: What is Smishing?
BOT: Smishing is a form of phishing that uses text messages (SMS) to deceive victims into clicking malicious links or divulging sensitive information.

USER: What is Tailgating?
BOT: Tailgating, also known as piggybacking, is a physical security breach where an unauthorized person follows an authorized person into a restricted area.

USER: What is Baiting in social engineering?
BOT: Baiting is a social engineering attack where an attacker leaves a malware-infected physical device, like a USB flash drive, in a place where it is sure to be found.

USER: What is Pretexting?
BOT: Pretexting is a social engineering technique where an attacker invents a scenario (a pretext) to engage a victim and trick them into divulging information or performing an action.

USER: What is Dumpster Diving in cyber security?
BOT: Dumpster diving is the practice of sifting through commercial or residential waste to find items that have been discarded, such as documents with passwords or sensitive data.

USER: What is a Denial of Service (DoS) attack?
BOT: A DoS attack is a cyber-attack in which the perpetrator seeks to make a machine or network resource unavailable to its intended users by temporarily or indefinitely disrupting services.

USER: What is a Distributed Denial of Service (DDoS) attack?
BOT: A DDoS attack is a malicious attempt to disrupt normal traffic of a targeted server, service, or network by overwhelming the target with a flood of Internet traffic from multiple sources.

USER: What is a Man-in-the-Middle (MitM) attack?
BOT: A MitM attack is a general term for when a perpetrator positions themselves in a conversation between a user and an application, either to eavesdrop or to impersonate one of the parties.

USER: What is ARP Spoofing?
BOT: ARP spoofing is a type of attack in which a malicious actor sends falsified ARP messages over a local area network, linking the attacker's MAC address with the IP address of a legitimate computer.

USER: What is DNS Spoofing?
BOT: DNS spoofing, or DNS cache poisoning, is a form of computer security hacking in which corrupt DNS data is introduced into the DNS resolver's cache, redirecting traffic to a malicious website.

USER: What is Session Hijacking?
BOT: Session hijacking, sometimes known as cookie hijacking, is the exploitation of a valid computer session to gain unauthorized access to information or services in a computer system.

USER: What is MAC Flooding?
BOT: MAC flooding is a technique employed to compromise the security of network switches by bombarding the switch with fake MAC addresses until its MAC table is full.

USER: What is an Evil Twin attack?
BOT: An evil twin is a fraudulent Wi-Fi access point that appears to be legitimate, set up to eavesdrop on wireless communications.

USER: What is a Rogue Access Point?
BOT: A rogue access point is a wireless access point that has been installed on a secure network without explicit authorization from a local network administrator.

USER: What is Packet Sniffing?
BOT: Packet sniffing is the practice of gathering, collecting, and logging some or all packets that pass through a computer network to monitor traffic or steal unencrypted data.

USER: What is SQL Injection (SQLi)?
BOT: SQL Injection is a web security vulnerability that allows an attacker to interfere with the queries that an application makes to its database, potentially allowing them to view or delete data.

USER: What is Cross-Site Scripting (XSS)?
BOT: XSS is a type of security vulnerability typically found in web applications, enabling attackers to inject malicious client-side scripts into web pages viewed by other users.

USER: What is the difference between Reflected and Stored XSS?
BOT: Reflected XSS occurs when a malicious script is bounced off a web server as an error message or search result. Stored XSS occurs when the malicious script is permanently stored on the target servers.

USER: What is Cross-Site Request Forgery (CSRF)?
BOT: CSRF is a web security vulnerability that allows an attacker to induce users to perform actions that they do not intend to perform while authenticated on a web application.

USER: What is Directory Traversal?
BOT: Directory traversal is a web security vulnerability that allows an attacker to read arbitrary files on the server that is running an application.

USER: What is Command Injection?
BOT: Command injection is a cyber attack that involves executing arbitrary commands on a host operating system via a vulnerable application.

USER: What is a Buffer Overflow attack?
BOT: A buffer overflow occurs when a program or process attempts to write more data to a fixed length block of memory (a buffer) than the buffer is allocated to hold, causing system crashes or allowing code execution.

USER: What is a Zero-Day Vulnerability?
BOT: A zero-day vulnerability is a software security flaw that is known to the software vendor but doesn't have a patch in place yet, making it highly susceptible to exploitation.

USER: What is a Zero-Day Exploit?
BOT: A zero-day exploit is a cyber attack that occurs on the same day a weakness is discovered in software, utilizing the zero-day vulnerability before a fix becomes available.

USER: What is a Brute Force Attack?
BOT: A brute force attack uses trial-and-error to guess login info, encryption keys, or find a hidden web page. Hackers work through all possible combinations hoping to guess correctly.

USER: What is a Dictionary Attack?
BOT: A dictionary attack is a form of brute force attack technique for defeating a cipher or authentication mechanism by trying to determine its decryption key or passphrase by trying hundreds or thousands of likely possibilities from a list.

USER: What is Credential Stuffing?
BOT: Credential stuffing is the automated injection of breached username/password pairs in order to fraudulently gain access to user accounts on other websites.

USER: What is a Rainbow Table attack?
BOT: A rainbow table attack is a password cracking method that uses a precomputed table of reversed cryptographic hash functions, usually used for cracking password hashes.

USER: What is Password Spraying?
BOT: Password spraying is an attack that attempts to access a large number of accounts (usernames) with a few commonly used passwords to avoid account lockouts.

USER: What is a Backdoor in cyber security?
BOT: A backdoor is a typically covert method of bypassing normal authentication or encryption in a computer, product, embedded device, or its embodiment.

USER: What is Privilege Escalation?
BOT: Privilege escalation is the act of exploiting a bug, a design flaw, or a configuration oversight in an OS or application to gain elevated access to resources that are normally protected from an application or user.

USER: What is an Advanced Persistent Threat (APT)?
BOT: An APT is a prolonged and targeted cyberattack in which an intruder gains access to a network and remains undetected for an extended period of time to steal data.

USER: What is Cryptography?
BOT: Cryptography is the practice and study of techniques for secure communication in the presence of adversarial behavior, converting plaintext into unreadable ciphertext.

USER: What is Plaintext?
BOT: Plaintext is information that a sender wishes to transmit to a receiver, written in a format that is readable by humans or machines without processing.

USER: What is Ciphertext?
BOT: Ciphertext is the result of encryption performed on plaintext using an algorithm, called a cipher, making it unreadable without the proper decryption key.

USER: What is Encryption?
BOT: Encryption is the process of encoding information in such a way that only authorized parties can access it and those who are not authorized cannot.

USER: What is Decryption?
BOT: Decryption is the process of taking encoded or encrypted text or other data and converting it back into text that you or the computer can read and understand.

USER: What is Symmetric Encryption?
BOT: Symmetric encryption is a type of encryption where only one key (a secret key) is used to both encrypt and decrypt electronic information.

USER: What is the main disadvantage of Symmetric Encryption?
BOT: The main disadvantage is the key distribution problem; if the secret key is intercepted during transmission, the attacker can decrypt all messages.

USER: What is Asymmetric Encryption?
BOT: Asymmetric encryption, also known as public-key cryptography, is a process that uses a pair of related keys—one public key and one private key—to encrypt and decrypt a message.

USER: How do Public and Private keys work together in Asymmetric Encryption?
BOT: A message encrypted with a person's public key can only be decrypted using that exact same person's private key.

USER: Which is faster, Symmetric or Asymmetric Encryption?
BOT: Symmetric encryption is generally much faster and requires less computational power than asymmetric encryption.

USER: What is the Advanced Encryption Standard (AES)?
BOT: AES is a highly secure symmetric-key encryption standard adopted by the U.S. government and widely used worldwide to protect sensitive data.

USER: What is RSA?
BOT: RSA (Rivest-Shamir-Adleman) is one of the first and most widely used public-key cryptosystems (asymmetric encryption) for secure data transmission.

USER: What is a Hash Function?
BOT: A hash function is a mathematical algorithm that maps data of arbitrary size to a fixed-size bit string (a hash), acting as a digital fingerprint for the data.

USER: What makes a cryptographic hash function secure?
BOT: It must be deterministic, quick to compute, impossible to reverse-engineer (one-way), and highly collision-resistant (no two different inputs produce the same hash).

USER: What is a Hash Collision?
BOT: A collision occurs when two distinct inputs to a hash function produce the exact same output hash value, which is a vulnerability in cryptography.

USER: What is Salt in password hashing?
BOT: A salt is random data that is used as an additional input to a one-way function that hashes data, passwords, or passphrases to defend against dictionary attacks and rainbow tables.

USER: What is a Digital Signature?
BOT: A digital signature is a mathematical scheme for verifying the authenticity of digital messages or documents, ensuring non-repudiation and data integrity.

USER: How is a Digital Signature created?
BOT: The sender hashes the message and then encrypts the hash with their own private key. The receiver uses the sender's public key to decrypt the hash and verify the message.

USER: What is Non-repudiation?
BOT: Non-repudiation ensures that a transferred message has been sent and received by the parties claiming to have sent and received the message, meaning the sender cannot deny sending it.

USER: What is a Digital Certificate?
BOT: A digital certificate is an electronic document used to prove the ownership of a public key, establishing trust between a client and a server.

USER: What is a Certificate Authority (CA)?
BOT: A CA is a trusted entity that issues digital certificates, verifying the identity of the certificate owner and binding their identity to a public key.

USER: What is Public Key Infrastructure (PKI)?
BOT: PKI is a set of roles, policies, hardware, software, and procedures needed to create, manage, distribute, use, store, and revoke digital certificates and manage public-key encryption.

USER: What is SSL/TLS?
BOT: Secure Sockets Layer and its successor Transport Layer Security are cryptographic protocols designed to provide communications security over a computer network, commonly used for HTTPS.

USER: What is Steganography?
BOT: Steganography is the practice of concealing a file, message, image, or video within another file, message, image, or video, hiding the very existence of the secret data.

USER: What is the difference between Cryptography and Steganography?
BOT: Cryptography scrambles a message to make it unreadable, while steganography hides the message so that no one even knows it exists.

USER: What is an Access Control List (ACL)?
BOT: An ACL is a list of rules that specifies which users or systems are granted or denied access to a particular object or system resource.

USER: What is the Principle of Least Privilege (PoLP)?
BOT: The principle of least privilege states that a subject should be given only those privileges needed for it to complete its task, and no more.

USER: What is Authentication?
BOT: Authentication is the process of recognizing a user's identity, ensuring that the person is who they claim to be, typically using credentials like usernames and passwords.

USER: What is Authorization?
BOT: Authorization is the security process that determines a user's access levels or privileges to resources after their identity has been authenticated.

USER: What is Multi-Factor Authentication (MFA)?
BOT: MFA is an authentication method that requires the user to provide two or more verification factors to gain access to a resource, such as a password and a fingerprint.

USER: What are the three common factors of Authentication?
BOT: Something you know (password), something you have (smart card or token), and something you are (biometrics like fingerprints).

USER: What is Single Sign-On (SSO)?
BOT: SSO is an authentication scheme that allows a user to log in with a single ID and password to any of several related, yet independent, software systems.

USER: What is Biometric Authentication?
BOT: Biometric authentication uses unique biological characteristics, such as fingerprints, facial recognition, or retina scans, to verify an individual's identity.

USER: What is Role-Based Access Control (RBAC)?
BOT: RBAC is a method of restricting network access based on the roles of individual users within an enterprise, rather than granting permissions on a per-user basis.

USER: What is Discretionary Access Control (DAC)?
BOT: DAC is an access control policy determined by the owner of an object, who has the discretion to grant or deny access to other users.

USER: What is Mandatory Access Control (MAC)?
BOT: MAC is a strict access control model in which the operating system or security kernel determines access based on security clearances and data classifications, not owner discretion.

USER: What is Zero Trust Architecture?
BOT: Zero Trust is a security framework requiring all users, whether inside or outside the organization's network, to be authenticated, authorized, and continuously validated before being granted access.

USER: What is Endpoint Security?
BOT: Endpoint security is the practice of securing endpoints or entry points of end-user devices such as desktops, laptops, and mobile devices from being exploited by malicious actors.

USER: What is an Antivirus?
BOT: Antivirus software is a computer program used to prevent, detect, and remove malware, traditionally relying on signature-based detection.

USER: What is Endpoint Detection and Response (EDR)?
BOT: EDR is an integrated endpoint security solution that combines real-time continuous monitoring and collection of endpoint data with rules-based automated response and analysis capabilities.

USER: What is an Indicator of Compromise (IoC)?
BOT: An IoC is a piece of digital forensics data, such as a malicious IP address or an unusual file signature, that indicates a system or network has been breached.

USER: What is Sandboxing in cyber security?
BOT: Sandboxing is a cyber security practice where you run code, observe and analyze it in a safe, isolated environment on a network that mimics end-user operating environments.

USER: What is a Honeypot?
BOT: A honeypot is a decoy computer system set up to attract cyber attackers, allowing security teams to study their methods, track their movements, and divert them from real assets.

USER: What is an Intranet?
BOT: An intranet is a private computer network contained within an enterprise that is used to securely share company information and computing resources among employees.

USER: What is an Extranet in terms of network security?
BOT: An extranet is a controlled private network that allows external parties, like partners or vendors, limited and secure access to a company's internal intranet.

USER: What is a DMZ (Demilitarized Zone) in networking?
BOT: A DMZ is a physical or logical subnetwork that contains and exposes an organization's external-facing services (like web and email servers) to an untrusted network, usually the internet, adding an extra layer of security.

USER: What is a VLAN (Virtual Local Area Network)?
BOT: A VLAN is a logical grouping of network devices that appear to be on the same LAN despite their geographical distribution, used to segment traffic and improve security.

USER: What is Network Access Control (NAC)?
BOT: NAC is a security solution that enforces policy on devices attempting to access a network, ensuring only compliant, authenticated, and authorized devices are granted access.

USER: What is MAC Filtering?
BOT: MAC filtering is a security access control method whereby the 48-bit MAC address assigned to each network card is used to determine access to the network.

USER: What is Port Security?
BOT: Port security is a layer 2 feature on network switches that restricts input to an interface by limiting and identifying MAC addresses of the stations allowed to access the port.

USER: What is WEP (Wired Equivalent Privacy)?
BOT: WEP is an early, outdated, and highly vulnerable wireless security protocol that should no longer be used due to its easily crackable encryption.

USER: What is WPA (Wi-Fi Protected Access)?
BOT: WPA was introduced as a temporary security enhancement over WEP, using TKIP (Temporal Key Integrity Protocol) to dynamically change keys, but it is now considered obsolete.

USER: What is WPA2?
BOT: WPA2 is the second generation of Wi-Fi Protected Access, providing stronger data protection and network access control by using the highly secure AES (Advanced Encryption Standard) encryption.

USER: What is WPA3?
BOT: WPA3 is the latest Wi-Fi security standard, offering improved cryptographic strength, individualized data encryption, and better protection against brute-force dictionary attacks.

USER: What is WPS (Wi-Fi Protected Setup) and why is it a risk?
BOT: WPS is a feature designed to make connecting to a secure router easier using a PIN. It is a major security risk because the PIN can be easily cracked via brute-force attacks.

USER: What is Wardriving?
BOT: Wardriving is the act of searching for Wi-Fi wireless networks by a person in a moving vehicle, using a portable computer or smartphone to map vulnerable networks.

USER: What is a Packet Filtering Firewall?
BOT: It is a basic, stateless firewall that operates at the network layer, filtering traffic based on source/destination IP addresses, ports, and protocols without inspecting the payload.

USER: What is a Stateful Inspection Firewall?
BOT: A stateful firewall keeps track of the state of active connections and makes decisions based on the context of the traffic as well as defined security rules.

USER: What is a Proxy Firewall?
BOT: A proxy firewall acts as an intermediary between in-house clients and the internet, inspecting traffic at the application layer and hiding the internal network's IP addresses.

USER: What is a Web Application Firewall (WAF)?
BOT: A WAF specifically filters, monitors, and blocks HTTP traffic to and from a web application, protecting against attacks like SQL injection and cross-site scripting (XSS).

USER: What is the difference between NIDS and HIDS?
BOT: A Network Intrusion Detection System (NIDS) monitors traffic across the entire network, while a Host-based Intrusion Detection System (HIDS) monitors traffic and activity on a single specific device.

USER: What is the Data Encryption Standard (DES)?
BOT: DES is a legacy symmetric-key algorithm for the encryption of digital data. It is now considered insecure due to its short 56-bit key length.

USER: What is 3DES (Triple DES)?
BOT: 3DES is a symmetric-key block cipher that applies the DES cipher algorithm three times to each data block to enhance security, though it is being phased out in favor of AES.

USER: What is Blowfish?
BOT: Blowfish is a fast, free, symmetric block cipher designed as an alternative to DES, utilizing a variable-length key from 32 bits to 448 bits.

USER: What is Elliptic Curve Cryptography (ECC)?
BOT: ECC is a modern approach to public-key cryptography based on the algebraic structure of elliptic curves, providing strong security with much shorter, faster keys than RSA.

USER: What is the Diffie-Hellman Key Exchange?
BOT: It is a secure method for two parties to securely exchange cryptographic keys over a public, unsecured channel, which can then be used for symmetric encryption.

USER: What is MD5 (Message Digest 5)?
BOT: MD5 is a widely used but deprecated cryptographic hash function producing a 128-bit hash value. It is vulnerable to hash collisions and is no longer secure for passwords.

USER: What is SHA (Secure Hash Algorithm)?
BOT: SHA is a family of cryptographic hash functions. SHA-1 is deprecated, while the SHA-2 family (including SHA-256) is currently the standard for secure hashing.

USER: What is a Certificate Revocation List (CRL)?
BOT: A CRL is a list of digital certificates that have been revoked by the issuing Certificate Authority (CA) before their scheduled expiration date and should no longer be trusted.

USER: What is OCSP (Online Certificate Status Protocol)?
BOT: OCSP is an internet protocol used for obtaining the revocation status of an X.509 digital certificate in real-time, serving as a faster alternative to CRLs.

USER: What is the X.509 standard?
BOT: X.509 is an international standard that defines the format of public key certificates used in many internet protocols, including TLS/SSL.

USER: What is Key Escrow?
BOT: Key escrow is an arrangement in which the cryptographic keys needed to decrypt ciphered data are held in escrow so that, under certain circumstances, an authorized third party may gain access.

USER: What is Attribute-Based Access Control (ABAC)?
BOT: ABAC is an access control paradigm whereby access rights are granted to users through the use of policies which combine attributes together (e.g., user role, time of day, location).

USER: What is Rule-Based Access Control (RuBAC)?
BOT: An access control model that is based on a list of predefined rules created by an administrator, common in firewalls and routers (like limiting access after 5 PM).

USER: What is Physical Access Control?
BOT: It involves restricting physical access to buildings, rooms, or physical IT assets using methods like locks, security guards, ID badges, and biometric scanners.

USER: What is Logical Access Control?
BOT: It involves controlling digital access to computer networks, system files, and data via user identification, passwords, and digital authentication protocols.

USER: What is False Acceptance Rate (FAR) in biometrics?
BOT: FAR is the probability that a biometric system will incorrectly authorize an unauthorized person.

USER: What is False Rejection Rate (FRR) in biometrics?
BOT: FRR is the probability that a biometric system will incorrectly reject access to an authorized person.

USER: What is Crossover Error Rate (CER)?
BOT: CER is the point where the False Acceptance Rate (FAR) and False Rejection Rate (FRR) are equal. A lower CER indicates a more accurate and reliable biometric system.

USER: What is Vulnerability Scanning?
BOT: Vulnerability scanning is an automated process of proactively identifying network, application, and security vulnerabilities that could be exploited by attackers.

USER: What is the difference between a Vulnerability Scan and a Penetration Test?
BOT: A vulnerability scan is automated and only identifies potential flaws, while a penetration test involves a human ethical hacker actively trying to exploit those flaws to prove the risk.

USER: What is the Reconnaissance phase in Penetration Testing?
BOT: Also known as footprinting, it is the initial phase where the tester gathers as much intelligence and information about the target system or organization as possible before attacking.

USER: What is Black-Box Testing in cyber security?
BOT: A penetration testing method where the ethical hacker has absolutely no prior knowledge of the internal network, code, or architecture they are attacking.

USER: What is White-Box Testing in cyber security?
BOT: A testing method where the ethical hacker is given full knowledge and access to the target's internal structures, source code, and network configurations beforehand.

USER: What is Gray-Box Testing?
BOT: A blend of black-box and white-box testing, where the tester has limited, partial knowledge of the internal network, simulating an attack by an insider or disgruntled employee.

USER: What is Post-Exploitation?
BOT: The phase of a penetration test that occurs after a system has been compromised, focusing on determining the value of the compromised system and maintaining access.

USER: What is Privilege Escalation in an attack?
BOT: Once an attacker gains low-level access to a system, they use techniques to gain higher-level permissions, such as administrative or root access.

USER: What is a Cyber Security Incident?
BOT: Any observable occurrence in a system or network that violates security policies, acceptable use policies, or standard security practices (e.g., a data breach).

USER: What is the Incident Response (IR) Lifecycle?
BOT: A structured approach to handling security incidents, typically comprising Preparation, Identification, Containment, Eradication, Recovery, and Lessons Learned.

USER: What happens during the Containment phase of Incident Response?
BOT: The security team isolates the compromised systems or networks to prevent the threat from spreading further and causing more damage.

USER: What happens during the Eradication phase?
BOT: The team finds the root cause of the incident and permanently removes the threat from the environment, such as deleting malware or disabling breached accounts.

USER: What happens during the Lessons Learned phase?
BOT: The final phase where the team reviews the incident to understand what happened, how well they responded, and how to improve security and procedures for the future.

USER: What is a Business Continuity Plan (BCP)?
BOT: A comprehensive document outlining how a business will continue operating during an unplanned disruption in service, covering all aspects of the business.

USER: What is a Disaster Recovery Plan (DRP)?
BOT: A specialized subset of the BCP that focuses specifically on restoring IT infrastructure, systems, and data after a catastrophic event.

USER: What is Recovery Time Objective (RTO)?
BOT: RTO is the maximum targeted or acceptable duration of time in which a business process or IT system must be restored after a disaster to avoid unacceptable consequences.

USER: What is Recovery Point Objective (RPO)?
BOT: RPO is the maximum acceptable amount of data loss measured in time. It determines how frequently backups must be taken (e.g., losing up to 4 hours of data).

USER: What is a Cold Site?
BOT: A backup facility that has basic power and physical security but no computer hardware or data installed. It takes the longest time to bring online after a disaster.

USER: What is a Hot Site?
BOT: A fully functional backup facility equipped with all necessary hardware, software, and near real-time data replication. It can be brought online almost instantly.

USER: What is a Warm Site?
BOT: A compromise between a cold and hot site; it has hardware and connectivity ready, but the data needs to be restored from backups before operations can resume.

USER: What is Cloud Security?
BOT: A set of policies, controls, procedures, and technologies that work together to protect cloud-based systems, data, and infrastructure.

USER: What is the Shared Responsibility Model in cloud computing?
BOT: A security and compliance framework that dictates that the cloud provider is responsible for the security *of* the cloud, while the customer is responsible for security *in* the cloud.

USER: What is a Cloud Access Security Broker (CASB)?
BOT: A CASB is a software tool or service that sits between an organization's on-premises infrastructure and a cloud provider's infrastructure to enforce security policies.

USER: What is a major security vulnerability in Internet of Things (IoT) devices?
BOT: IoT devices often come with hardcoded, unchangeable default passwords and lack mechanisms for firmware updates, making them easy targets for botnets.

USER: Why is firmware updating critical for IoT security?
BOT: Firmware updates patch known security vulnerabilities. Without them, IoT devices remain permanently exposed to discovered exploits.

USER: What is Edge Computing Security?
BOT: Securing the data processed at the edge of the network (near the data source, like IoT devices) before it is sent to the central cloud, reducing the attack surface during transit.

USER: What is an Acceptable Use Policy (AUP)?
BOT: A document stipulating constraints and practices that a user must agree to for access to a corporate network or the internet.

USER: What is a Non-Disclosure Agreement (NDA)?
BOT: A legally binding contract establishing a confidential relationship, preventing employees or partners from sharing sensitive corporate information with competitors or the public.

USER: What is a Service Level Agreement (SLA)?
BOT: A contract between a service provider and a customer that specifies the level of service expected, including uptime guarantees and security responsibilities.

USER: What is Security Awareness Training?
BOT: Educational programs designed to train employees on potential cyber threats (like phishing and social engineering) and how to recognize and avoid them.

USER: Why are Phishing Simulations used in corporate environments?
BOT: They are used to test employees' ability to recognize malicious emails in a safe environment, identifying who needs further security training.

USER: What is a Clean Desk Policy?
BOT: A corporate directive that requires employees to clear their desks of all sensitive information (notes, post-its, printed documents) at the end of the day to prevent physical data theft.

USER: What is BYOD (Bring Your Own Device) Security?
BOT: The security strategies and policies implemented to protect corporate data when employees use their personal smartphones and laptops for work purposes.

USER: What is Mobile Device Management (MDM)?
BOT: MDM is a type of security software used by an IT department to monitor, manage, and secure employees' mobile devices that are deployed across multiple mobile service providers.

USER: What is Data Loss Prevention (DLP)?
BOT: DLP is a set of tools and processes used to ensure that sensitive data is not lost, misused, or accessed by unauthorized users, often by preventing data exfiltration.

USER: What is Data Exfiltration?
BOT: Data exfiltration is the unauthorized transfer, copying, or retrieval of data from a computer or server, usually performed by cybercriminals or malicious insiders.

USER: What is a VPN (Virtual Private Network)?
BOT: A VPN creates a secure, encrypted tunnel over a public network (like the internet), protecting the user's data from interception and hiding their IP address.

USER: What is IPSec (Internet Protocol Security)?
BOT: IPSec is a suite of protocols used to secure internet protocol (IP) communications by authenticating and encrypting each IP packet of a communication session.

USER: What is the difference between IPSec Transport mode and Tunnel mode?
BOT: Transport mode encrypts only the payload of the IP packet, while Tunnel mode encrypts the entire original IP packet, adding a new IP header for routing.

USER: What is a Honeytoken?
BOT: A honeytoken is a fake data record, such as a bogus email address or database entry, designed to be stolen by an attacker. Its use immediately alerts administrators to a breach.

USER: What is Network Segmentation?
BOT: The practice of dividing a computer network into smaller, isolated subnets. If one segment is breached, the attacker cannot easily access the rest of the network.

USER: What is an Air Gap?
BOT: An air gap is a security measure that involves isolating a computer or network and preventing it from establishing an external connection, ensuring it is physically disconnected from the internet.

USER: What is a Side-Channel Attack?
BOT: An attack based on information gained from the physical implementation of a computer system, rather than weaknesses in the implemented algorithm itself (e.g., power consumption, electromagnetic leaks).

USER: What is a Logic Analyzer used for in hardware security?
BOT: It is an electronic instrument that captures and displays multiple signals from a digital system or digital circuit, used to reverse-engineer hardware or sniff bus communications.

USER: What is Ransomware-as-a-Service (RaaS)?
BOT: RaaS is a cybercrime business model where malware developers sell or lease ransomware variants to affiliates who then use them to perform attacks, sharing the profits.

USER: What is a Cryptojacking attack?
BOT: Cryptojacking is the unauthorized use of someone else's computer or server processing power to mine cryptocurrency, significantly slowing down the victim's device.

USER: What is the Principle of Defense in Depth?
BOT: An information security concept in which multiple layers of security controls are placed throughout an IT system. If one fails, another layer catches the threat.

USER: What is a Security Operations Center (SOC)?
BOT: A centralized facility where an enterprise's information security team continuously monitors, detects, analyzes, and responds to cybersecurity incidents.

USER: What is SIEM (Security Information and Event Management)?
BOT: A software solution that aggregates and analyzes activity from many different resources across your entire IT infrastructure in real-time to identify security anomalies.

USER: What is Threat Hunting?
BOT: The proactive and iterative search through networks to detect and isolate advanced threats that evade existing security solutions, rather than waiting for an alert.

USER: What is Open Source Intelligence (OSINT)?
